# Task Management System for Small Teams

A web-based Task Management System developed as part of the Algonive Web Development Internship.

## Features
- User Authentication (Signup/Login)
- Task Assignment
- Task Status Updates
- Deadline Reminders
- Due Dates
- Local Storage Support
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firestore Database

## Project Purpose
This application helps small teams and startups assign, track, and manage daily work efficiently.
